# Sales KPI Dashboard

## 📌 Project Overview

This project analyzes sales performance using key business metrics and interactive dashboards.

## 🎯 Objective

To monitor sales KPIs, identify top-performing products and regions, and understand overall business performance.

## 🛠️ Tools Used

* Power BI
* Excel
* DAX

## 📊 Key KPIs

* Total Sales
* Total Profit
* Total Quantity
* Average Sales

## 📈 Dashboard Analysis

* Sales by Region
* Sales by Category
* Monthly Sales Trend
* Top Products
* Profit Analysis

## 💡 Key Insights

* Identified high-performing regions and products.
* Analyzed monthly sales trends.
* Compared sales and profit performance.
* Used interactive filters for business analysis.

## 👩‍💻 Skills Demonstrated

* Data Cleaning
* Data Analysis
* Data Visualization
* DAX
* Dashboard Development
* Business Insights
